# 「一步一步」Step by Step

> 把大任務拆成小步，讓小朋友自己走完。
> 兒童自律訓練＋親子共玩 Web App · 純前端 · 可離線 · 支援廣東話語音朗讀

一個畀 6–9 歲小朋友同家長一齊用嘅日常 Routine App。核心概念來自執行功能（EF）研究：
小朋友唔係「唔聽話」，而係工作記憶裝唔低多步指令。呢個 App 將「阿媽嗌到聲沙」嘅日常
指令，變成小朋友自己睇得明、撳得到、完成到嘅**視覺化步驟卡**。

## ✨ 功能

**小朋友端（大、圓、慢、肯定）**
- 📇 **一步一步**：每個任務拆成 4–6 張全屏單步卡，一步一屏，完成一張先見下一張
- 🐾 **長按 1 秒完成掣**：防誤撳跳步，畀小朋友「我決定完成」嘅儀式感
- 🔊 **語音朗讀**：廣東話（zh-HK）為主，普通話（zh-CN）／英文（en-US）一撳切換，跟讀高亮
- 🙋 **求助掣**：「我唔識」唔係失敗，家長端會記低邊步最常卡住
- ⭐ **星星罐／成長地圖／任務圖鑑**：正向記錄，唔做排行榜、唔做懲罰
- 🎮 **三個小遊戲**：記憶配對、步驟排一排、聽聲選卡（全部配合語音）

**家長端（控制台，PIN 保護）**
- 📚 15 個預設任務一鍵開關，全部拆好步驟，即開即用
- ✏️ 任務編輯：改文字、換 emoji 圖示、**用自己屋企嘅相做卡圖**、加減調轉步驟
- 🗓️ 時間表：設定邊日、幾點時段出現邊個任務
- 📊 週報告：完成率走勢、最常卡住嘅步驟、最常未完成嘅任務（可列印 PDF）
- 👶 多小朋友檔案、家長補完成、大字模式、減少動畫
- 📤 資料匯出／匯入備份

## 🔊 語音支援

用瀏覽器原生 `SpeechSynthesis`，唔需要網絡、唔需要 API key。

| 語言 | 代碼 | 備註 |
|---|---|---|
| 廣東話 | `zh-HK` | iOS／macOS Safari 內置較完整；Android 需 Google 語音 |
| 普通話 | `zh-CN` | 大部分裝置內置 |
| English | `en-US` | 大部分裝置內置 |

如果系統冇某個語言嘅聲音，App 會自動用最接近嘅代替，並喺「家長端 → 設定 → 檢查語音支援」顯示。

## 💾 資料儲存

所有資料（任務改動、完成記錄、星星、相片）只儲存喺**瀏覽器 localStorage**，
唔會傳去任何伺服器。換機或清快取前，請喺「家長端 → 設定 → 匯出備份」。

## 🛠️ 本地開發

```bash

python3 -m http.server 8080
# 開 http://localhost:8080
```

重新產生圖示：

```bash
python3 tools/make_icons.py
```

## 📐 設計語言

**大**（觸控目標 ≥ 72px）· **圓**（安全感）· **慢**（唔催促、無倒數）· **肯定**（永遠正向語句）

| 角色 | 色值 | 用途 |
|---|---|---|
| Mint | `#1F9E94` | 完成掣、進度、家長主按鈕 |
| Orange | `#F07A1F` | 星星、慶祝 |
| Cream | `#FFF8EE` | 小朋友端背景 |
| Ink | `#2B2B2B` | 正文（唔用純黑） |
| Soft Red | `#E86A6A` | 只用喺「求助」掣 |

唔用紅綠做對錯：做錯唔會變紅，Gin 只會講「我哋再試下呢步」。

## 🧠 設計依據

| EF 組成 | App 對應設計 |
|---|---|
| 工作記憶 | 一步一屏，永不顯示全清單壓力 |
| 衝動抑制 | 完成掣需長按 1 秒 |
| 認知彈性 | 步驟可調次序、家長可臨時插入 |
| 自我監察 | 每步圖像打勾，結尾有回顧頁 |
